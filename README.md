# سامانه مدیریت رخداد شهری مبتنی بر هوش مصنوعی

## Smart Urban Incident Management System

یک پلتفرم هوشمند مدیریت رخدادهای شهری که شهروندان می‌توانند رخدادها را گزارش دهند، هوش مصنوعی به‌طور خودکار نوع، شدت و سازمان مسئول را تشخیص می‌دهد، و مدیران روند رسیدگی را پیگیری می‌کنند.

## ویژگی‌ها

- **احراز هویت OTP**: ورود با شماره موبایل و کد تایید ۵ رقمی (شبیه‌سازی پیامک)
- **گزارش رخداد**: فرم چندمرحله‌ای با آپلود تصویر، انتخاب موقعیت روی نقشه، و توضیحات
- **استخراج GPS از EXIF**: استخراج خودکار مختصات از عکس
- **تحلیل هوش مصنوعی**: تحلیل تصویر و توضیحات با GPT-4o (با fallback کلمه‌کلیدی فارسی)
- **نقشه نشان**: نقشه تعاملی با جستجوی آدرس، انتخاب موقعیت، و نمایش رخدادها
- **داشبورد مدیریتی**: آمار، نمودارها (Recharts)، مدیریت رخدادها
- **پنل اپراتور**: مشاهده رخدادهای محول شده و به‌روزرسانی وضعیت
- **PWA**: نصب روی موبایل، آفلاین‌کش، RTL فارسی

## نقش‌ها

1. **شهروند (CITIZEN)**: ثبت رخداد، مشاهده گزارش‌های خود
2. **مدیر (ADMIN)**: داشبورد تحلیلی، مدیریت همه رخدادها، نقشه رخدادها
3. **اپراتور سازمان (AGENCY)**: مشاهده رخدادهای محول شده، به‌روزرسانی وضعیت

## تکنولوژی‌ها

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui + Lucide Icons
- Prisma ORM + SQLite
- React Hook Form + Zod
- Recharts
- OpenAI GPT-4o API
- Neshan Map SDK (پروکسی امن از backend)

## نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# ایجاد دیتابیس و اجرای migration
npx prisma migrate dev

# پر کردن دیتابیس با داده نمونه
npx prisma db seed

# اجرای پروژه
npm run dev
```

سپس به آدرس http://localhost:3000 مراجعه کنید.

## متغیرهای محیطی

فایل `.env` با مقادیر زیر ایجاد شده است:

```
DATABASE_URL="file:./dev.db"
JWT_SECRET="..."
OPENAI_API_KEY=""
OPENAI_API_BASE_URL="https://api.openai.com/v1"
NESHAN_API_KEY="..."
```

فایل `.env.example` به عنوان الگو موجود است.

### تنظیم کلیدهای واقعی

- **OpenAI**: کلید API واقعی OpenAI را در `OPENAI_API_KEY` قرار دهید. اگر خالی باشد، سیستم از تحلیل کلمه‌کلیدی فارسی استفاده می‌کند.
- **Neshan Map**: کلید API نشان را در `NESHAN_API_KEY` قرار دهید. در حالت نمونه، از داده‌های شبیه‌سازی شده استفاده می‌شود.

## کاربران نمونه (پس از seed)

| نقش | شماره موبایل | نام |
|------|-------------|-----|
| مدیر | 09120000001 | مدیر سیستم |
| شهروند | 09120000002 | علی رضایی |
| شهروند | 09120000003 | مریم احمدی |
| اپراتور شهرداری | 09120000004 | اپراتور شهرداری |
| اپراتور آتش نشانی | 09120000005 | اپراتور آتش نشانی |

برای ورود، شماره موبایل را وارد کنید و کد تایید ۵ رقمی نمایش داده شده در toast را وارد کنید.

## ساختار پروژه

```
app/                    # صفحات و API routes
  api/                  # Backend API routes
  admin/                # پنل مدیریت
  agency/               # پنل اپراتور
  dashboard/            # داشبورد مشترک
components/
  map/                  # کامپوننت نقشه نشان
  dashboard/            # کامپوننت‌های داشبورد
  forms/                # فرم‌ها
  ui/                   # کامپوننت‌های UI (shadcn)
lib/                    # ابزارها (prisma, auth, otp)
services/               # سرویس‌ها (AI, Neshan)
hooks/                  # React hooks
types/                  # تعریف انواع TypeScript
prisma/                 # schema و seed
```

## امنیت

- کلید API نقشه نشان فقط در backend استفاده می‌شود (پروکسی `/api/map`, `/api/geocode`, `/api/search-location`)
- session با JWT در cookie امن (httpOnly)
- middleware برای محافظت از مسیرها
- اعتبرسنجی با Zod در همه API routes
